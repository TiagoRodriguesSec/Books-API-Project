# Open Library Book Search App

A desktop application built with Python that interfaces with the Open Library Search API to search for books and authors, manage a search history, and handle a list of favorites.

## Features

- Search books by title or author using the Open Library API.
- Save and view search history locally (`Historico.json`).
- Manage a favorites list (add from history and remove items).
- Graphical User Interface built with Tkinter.

## Technologies Used

- Python
- Tkinter (GUI)
- Requests (HTTP requests)
- JSON (Data persistence)

## How to Run

1. Make sure you have Python installed.
2. Install the required dependency:
   `pip install requests`
